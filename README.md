## 📂 Projects

### 🏥 1. [SmartClaim-Engine](./SmartClaim-Engine)
An intelligent health insurance claims adjudication assistant built with **LangGraph**, **Google Gemini (`gemini-3.5-flash-lite`)**, and **Streamlit**.

- **Corrective RAG (Self-RAG):** Automated intent routing, document grading, and query rewriting loops.
- **Multimodal Vision OCR:** Dynamic bill parsing across `.pdf`, plain text, and images (`.png`, `.jpg`, `.webp`).
- **Zero-Hallucination Math:** Deterministic Python calculations for approved payouts, deductibles, and out-of-pocket liabilities.
- **Stateful Memory:** Checkpointed multi-turn session persistence.

👉 See the [SmartClaim-Engine Documentation & Setup Guide](./SmartClaim-Engine/README.md) for full details.
